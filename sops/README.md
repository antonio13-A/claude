[Início](../README.md)

SOP significa procedimento operacional padrão. Usa-o para executar e resolver exceções, não apenas marcar caixas.
Cada procedimento deve deixar uma saída verificável. A IA pode ajudar; o responsável continua a confirmar fontes, contexto e publicação.

## Como usar
Começa pelo [caderno](../templates/ciclo.md). Abre o procedimento da etapa atual; preenche saídas e pendências.
Quando um passo falhar, regista a falha e a ação de recuperação. Se o procedimento não a cobrir, propõe uma melhoria.
Versão utilizada, responsável, tempo previsto e tempo real acompanham cada execução.
