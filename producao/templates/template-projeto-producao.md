# Ficha-Mestra de Projeto de Produção

> **O documento central do Modelo de Produção.** Esta ficha organiza *todos* os dados brutos de uma produção, da ideia ao arquivo, num único sítio. É copiada por cada nova produção e **viaja com ela** ao longo de todo o fluxo do DOS — **CAPTURA → TRANSFORMAÇÃO → ORGANIZAÇÃO FINAL** — recolhendo dados em cada fase.
>
> Copia este ficheiro para um novo. Nome sugerido: `proj-[nº]-[titulo-curto].md`. Preenche à medida que avanças pelas [fases](../fases/). No fim, esta ficha arquiva com a produção em `../../memoria/arquivo-episodios/`.
>
> Ver o [Manual de Produção](../README.md) para o enquadramento. Cada secção liga-se a uma fase e/ou SOP.
