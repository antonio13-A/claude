# Reutilização e autoria
O projeto foi organizado para facilitar estudo, revisão e ensino.
Esta versão não adiciona uma licença de reutilização aberta. Uma escolha de licença pelo titular deve definir o que terceiros podem copiar, adaptar e redistribuir.
Até essa definição, pedir autorização para reutilização de materiais próprios e verificar separadamente fontes de terceiros.
Modelos, gravações, marcas, fotografias e citações podem ter condições distintas. Acesso público não substitui essas condições.
Ao ensinar, identificar autoria, versão do método, origem dos exemplos e limites do que foi testado.
