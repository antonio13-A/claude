# _inbox — Entrada bruta

> Este é o teu despejo bruto. Tudo o que aparece — uma ideia, um link, um ficheiro, uma nota de voz transcrita, um recorte — entra **primeiro** aqui. O objetivo é simples: **não perder nada**.

A fricção de decidir "onde é que isto vive?" é o que faz as boas ideias evaporarem. Aqui não decides nada. Só capturas. Arrumar é uma tarefa separada, feita com calma.

---

## Como funciona

1. **Captura sem pensar.** Cria um ficheiro ou cola aqui. Nome livre. Sem estrutura obrigatória.
2. **Arruma depois.** Em sessões dedicadas (idealmente semanais), esvazias o inbox: cada item vai para a camada certa (`marca/`, `estrategia/`, `producao/`, `memoria/`...) ou é descartado.
3. **Mantém-no vazio-ish.** Um inbox cheio é ruído. Um inbox arrumado com frequência é um motor.

---

## Regra dos 30 dias

> **Nada fica no `_inbox/` mais de 30 dias sem ser arrumado.**

Se um item passou 30 dias aqui, decide já: arruma-o para o sítio certo ou apaga-o. Um inbox que nunca é esvaziado deixa de ser inbox e passa a ser um monte de entulho.

---

## O que registar no topo de cada item (opcional, mas ajuda)

> - **Data de entrada:** [preencher]
> - **Fonte:** [preencher — onde/como surgiu]
> - **Próxima ação:** [preencher — arrumar para X / desenvolver / descartar]

---

## Checklist de arrumação (fazer periodicamente)

- [ ] Percorri todos os itens do inbox
- [ ] Cada item foi movido para a camada certa ou descartado
- [ ] Nenhum item tem mais de 30 dias
- [ ] Ideias promissoras foram transformadas em fichas (`producao/templates/`)
