# Casos reais
Ainda não foi incorporado neste repositório um caso real completo e verificado.
Para adicionar: copiar [modelo](../templates/caso-pap.md), ligar provas, completar limites e passar pela [revisão pública](../docs/publicacao.md).
Não colocar exemplos didáticos nesta pasta como se fossem realizações.
Os originais podem permanecer privados; descrever quais provas sustentam o relato e que limitações de acesso existem.
